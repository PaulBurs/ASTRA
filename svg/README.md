# svg

Статические макеты экранов интерфейса ASTRA: 30 файлов SVG 1600×1040 и их растровые копии PNG 1600×1040 в `png/` с теми же именами. Название экрана — в `<title>` каждого SVG.

| Префикс | Роль в шапке макета | Файлы | Экраны |
|---|---|---|---|
| `D` | Диспетчерская | D01–D16, D19 | Предупреждения, наблюдение, назначение проверки, объекты, карточка объекта, карта, журнал прогнозов, проверки и их результат, заявки на работы, уведомления, критическое предупреждение, завершённые проверки |
| `S` | Диспетчерская | S01, S02 | Состояния: «Нет предупреждений», «Данные источника устарели» |
| `T` | Технический специалист | T01–T11 | Мои проверки, статусы проверки (Новое / Принято / В работе), форма результата осмотра, завершение, карточка объекта, препятствие, уведомления |

## Использование

- Эталон при вёрстке [`../frontend/src/`](../frontend/src/) (например, экран S01 в `WarningsPage`).
- PNG из `png/` копировались в `frontend/src/assets/screens/` как заглушки страниц; история — в [`../frontend/CHANGELOG.md`](../frontend/CHANGELOG.md).
- Прямых ссылок на `svg/` из кода и конфигурации нет; файлы не участвуют в сборке.
