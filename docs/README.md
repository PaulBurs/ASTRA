# ASTRA Documentation

Дополнительная техническая документация проекта.

Корневой `README.md` является основной точкой входа для разработчиков.

В эту директорию можно добавлять:

- описание архитектуры;
- ER-диаграммы базы данных;
- описание ML pipeline;
- схемы REST API;
- решения по архитектуре;
- инструкции по развёртыванию;
- материалы для демонстрации проекта.

Документы, относящиеся только к конкретному модулю, лучше хранить
рядом с этим модулем.
