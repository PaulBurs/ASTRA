# ASTRA — ML workspace

Эта директория предназначена для разработки ML-части проекта ASTRA.

## Что делает ML-часть

ML-модель должна оценивать вероятность аварии / отказа оборудования
инженерной инфраструктуры.

Backend ASTRA получает прогноз через единый ML-интерфейс.

На текущем этапе используется тестовая реализация `DummyMLService`.
