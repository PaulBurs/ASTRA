# ASTRA Data

Общая директория для данных проекта ASTRA.

## Назначение

Здесь могут находиться:

- примеры входных данных;
- обезличенные тестовые наборы;
- файлы для локальной разработки;
- временные данные импорта.

Большие датасеты не должны коммититься в Git.

Файлы, загружаемые пользователями во время работы приложения,
следует помещать в `data/uploads/`. Эта директория игнорируется Git.

## Для ML-разработчиков

ML-код должен использовать эту директорию как общий источник данных,
если иной источник не согласован с командой.

Не создавайте отдельные копии одного и того же датасета внутри `ml/`.
